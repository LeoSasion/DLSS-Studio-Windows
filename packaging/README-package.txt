DLSS Studio — Windows x64 一键部署包

一、开始使用
1. 将 ZIP 完整解压到可写文件夹，例如 D:\Apps\DLSS Studio。
2. 双击“DLSS Studio.exe”，直接进入内嵌浏览器的独立工作台窗口。也可使用“启动工作台.bat”。
3. 窗口无系统边框，右上角可最小化、关闭；拖动顶部空白区域移动窗口，拖动外缘调整大小。
4. 上传图片或视频，选择增强参数，开始处理。

运行环境、Python 依赖、FFmpeg 和原始 DLSS 引擎均已内置；首次启动无需安装 Python、pip 或下载依赖。无需管理员权限。独立窗口使用 Microsoft WebView2：已安装时可直接运行；缺少时会询问是否安装包内的微软引导组件（仅首次安装此浏览器组件需要联网）。也可以使用 WebUI启动器在现有浏览器中打开。
请保留整个文件夹结构，不要单独移动 EXE，也不要直接从压缩包内运行。

二、两个入口
DLSS Studio.exe：直接显示工作台的独立桌面窗口，自动启动服务，关闭后停止该窗口的服务。
WebUI启动器.exe：保留传统启动中心，在外部浏览器中打开工作台。以下管理按钮属于 WebUI启动器：
• 启动并打开：启动此部署包的服务并打开浏览器。
• 打开网页：再次打开当前服务。
• 停止服务：停止此窗口启动的服务及其处理进程。
• 输出文件夹：查看 app\ui_out 下的结果。
• 查看日志：打开 logs 文件夹，server.log 记录 WebUI 服务运行信息，desktop-server.log 记录独立窗口服务信息，desktop.log 记录窗口启动异常。
默认地址为 http://127.0.0.1:7860/。若端口被占用，会从 7861 起选择可用端口；以窗口显示的地址为准。
WebUI启动器需要保持开启。独立窗口空闲时直接关闭；正在处理时会询问是否中断。两个入口各自管理自己的后台服务。服务仅监听此电脑的 127.0.0.1。

三、系统与显卡
目标平台：Windows 10/11，64 位 x64。启动窗口使用 .NET Framework 4.6.2 或更高版本（现代 Windows 通常已内置）。
需要兼容原始 video2dlssnr / DLSS NR 的 NVIDIA 显卡和驱动。此包不安装或修改显卡驱动，也不会让不支持的显卡获得 DLSS NR 能力。
当前工作站已测试 RTX PRO 6000 Blackwell、591.86 驱动的图片和短视频神经渲染；其他硬件需实际验证。
视频显卡编码另有驱动要求，程序启动时检查可用性。不满足时默认使用 ProRes（CPU 编码），文件体积可能较大。

四、数据和外观
原始上传：app\uploads\
输出结果：app\ui_out\<任务编号>\
重启服务后需重新上传素材，已输出文件仍保留。此发布包不包含工作目录的历史上传、处理结果或日志。
深色与浅色主题可在网页右上角切换。已包含最终版样式：深色折射边缘、浅色统一中性渐变与阴影、透明预览背景。

独立窗口的主题与浏览器数据保存在 desktop-profile\；此目录不会打入发布包。

五、排查
启动失败：查看 logs\server.log，确认已经完整解压且目录可写。
处理失败：查看网页底部状态按钮中的任务日志。
显卡或编码不兼容：更新显卡驱动，或改用支持的 CPU 编码选项；CPU 编码仍需要兼容显卡进行 DLSS 神经渲染。

源代码：app\web 为前端，app\studio_server.py 为服务，launcher-source\Launcher.cs 为 WebUI启动器源码，launcher-source\DesktopShell.cs 为独立窗口源码。
第三方说明：licenses\。文件 SHA-256 清单：manifest.json。
